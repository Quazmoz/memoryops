## Start using your memories

You're connected! Here's how to get the most out of MemoryOps:

- **Browse** — open the **MemoryOps** view in the Activity Bar to see recent
  memories, filter by type/pinned, and search.
- **Search** — press <kbd>Cmd/Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>M</kbd> or run
  `MemoryOps: Search Memory`.
- **Capture** — select code or notes and run
  `MemoryOps: Save Selection as Observation`
  (<kbd>Cmd/Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd>).
- **Retrieve context** — run `MemoryOps: Retrieve Context for Current File`
  to pull relevant memories for what you're working on.
- **Ask in chat** — if you have GitHub Copilot Chat, type
  **`@memoryops`** to query your workspace conversationally.
- **Inline hints** — enable `memoryops.enableCodeLens` to see how many
  memories reference the file you're editing.

Happy remembering! 🧠
